## Unsupported behavior and user-visible fallback

The fork must describe the current Windows Codex shared route as unavailable until the native spike passes. Claude unified mode remains unverified; OpenCode 2.0.15 has bounded native attach/response evidence but no verified production companion capability. Keep the locally usable native terminal and display an explicit limited/offline/unsupported companion state. An unverified or expired request must not send keystrokes, switch permission mode, start another executing process or enter a blind retry queue.

Transcript/status visibility can be offered only if independently proven and labeled. It is not a fallback certification for permissions, questions or ordinary remote messages. The same rule applies to custom ACP and terminal-only adapters.
